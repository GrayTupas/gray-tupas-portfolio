01 · Problem

Problem

I use AI for the same kinds of work every week. Without a setup, each new conversation needs my tools, rules and file conventions explained again, and files end up wherever they were made.

02 · My role

My role

I designed the whole setup: the Skills, the Projects, the Drive structure and the naming convention. I use it every day.

03 · How it works

How it works

Every request follows the same path. Nothing leaves the workspace until I approve it.

  • Skills. Each of the 9 Skills is a reusable instruction set that encodes my tools, rules and approval steps for one kind of work.
  • Projects. Projects are organised by work stream, so each stream keeps its own context.
  • Drive. Google Drive has 8 numbered root folders, from 00 Inbox to 07 Archive.
  • Names. Every file follows YYYY-MM Type - Descriptor (context).
04 · Key decisions

Key decisions

  • I approve first. I approve before anything is sent, submitted or filed. This rule runs through every Skill.
  • Rules live in the Skill. My tools, rules and approval steps are written once in each Skill, so I don't restate them in every conversation.
  • One naming convention. Every file uses the same pattern, so I can find it by date, type and context.
  • Nothing is deleted. Files that are no longer needed go to the Archive folder.
