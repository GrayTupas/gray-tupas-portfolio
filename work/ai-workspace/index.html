how I did it

Every request takes the same path.

I designed the whole setup: the Skills, the Projects, the Drive structure and the naming convention. Nothing leaves the workspace until I approve it.

  1. I ask for somethingA report, a filing, a prompt, a reply.
  2. A Skill takes overOne of 9 custom Skills supplies my tools, rules and approval steps.
  3. Claude drafts itInside a Project, so each work stream keeps its own context.
  4. I approveBefore anything is sent, submitted or filed.
  5. Filed in Drive8 numbered folders from 00 Inbox to 07 Archive. Nothing is deleted; it goes to Archive.

  • One naming convention. Every file follows YYYY-MM Type - Descriptor (context), so I can find it by date, type and context.
  • Nothing is deleted. Files that are no longer needed go to the Archive folder.
